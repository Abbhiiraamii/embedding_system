## Description

This assignment implements a capability embedding and composition system using Python. It represents capabilities, system states, and goals as numerical embeddings and uses cosine similarity to measure their relationships.

The program performs experiments on capability compatibility, input-output compatibility, capability composition, alternative implementations, goal relevance, operational attributes, state relationships, capability similarity, consistency, and efficiency.

It also evaluates the results using different criteria and generates a `capability_dataset.csv` file containing the capability information and operational attributes.

## Technologies Used

* Python
* NumPy
* Pandas
* Scikit-learn
* Cosine Similarity

## Main Features

* State embedding
* Goal embedding
* Capability embedding
* Capability compatibility checking
* Input-output compatibility checking
* Capability composition
* Goal relevance analysis
* Operational scoring
* Similarity calculations
* Consistency and efficiency testing
* Experimental dataset generation
